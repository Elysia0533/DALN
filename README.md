# vBook

Ung dung doc sach da nen tang, ho tro sach tu Google Drive, tep cuc bo va nguon mo rong.

## Cong nghe

- Flutter va Dart
- Material 3
- Kotlin, QuickJS va Flutter Platform Channels tren Android
- Firebase Authentication va Cloud Firestore
- Google Drive API
- SQLite voi `sqflite`
- SharedPreferences
- EPUB, PDF, TXT va Text-to-Speech
